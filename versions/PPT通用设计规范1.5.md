# PPT 通用设计规范 1.5

版本：1.5 · 2026-10-30

以 0.8 为主体，仅补充固定字号与配色确认。

适用于课程展示、项目汇报、研究报告、作品集、产品介绍等不同主题的演示文稿。视觉方向沿用 0.8 的**大标题、真实图片、半调印刷质感和克制的几何构成**；配色在开始前确认，纸白与克莱因蓝作为可选参考。

本规范记录可跨主题复用的设计偏好。题目、受众、章节、页数、案例和图片题材由每次任务决定；有明确品牌规范或新的设计要求时，按当次要求调整。

## 1. 核心原则

1. **先让主题醒目。** 页面标题、关键概念和主要图像要有明显的视觉重量，观众先看出这一页讲什么，再读解释。
2. **标题对应内容。** 已有大纲时沿用其中的章节名和主题名；长说明可移到副标题，核心题意保留。
3. **大段内容有独立章节封面。** 用大标题和主视觉形成节奏，区分章节层级。
4. **优先用真实图片做设计。** 选择摄影、作品、实物、建筑或项目截图，再通过抠图、裁切和色调处理融入版面。
5. **留白承担分隔作用。** 通过对齐、字号、间距和细线组织信息，避免每页都堆成相同的卡片。
6. **装饰服从阅读。** 去掉没有信息或构图作用的粗横条、竖条、底座条，装饰避开文字和页码。
7. **交付画面只面向观众。** 制作说明、编辑待办、对委托人的建议放在交付说明中，不写进幻灯片正文。

## 2. 画布与布局

| 项目      | 默认规范                       |
| ------- | -------------------------- |
| 比例      | 16:9                       |
| 设计与预览基准 | 1920 × 1080px              |
| PPT 页面  | 宽屏；物理尺寸可按软件设置，保持 16:9      |
| 页面背景    | 纸白 `#FBFAF7`               |
| 画布外背景   | 暖灰白 `#F1EFE9`              |
| 左右安全边距  | 约 72–96px                  |
| 顶部内容起点  | 约 125–150px，给页眉留出空间        |
| 底部预留    | 约 110–140px，容纳页码和注记        |
| 栏间距     | 约 48–80px                  |
| 常用布局    | 左文右图、左右对照、上下层级、横向流程、大图配短说明 |

以上间距是起点，根据内容密度调整。建立贯穿全稿的对齐线，同类页面共用标题位置、页码位置和边距。

网页预览时等比缩放，不限制放大倍率。原规范中的 1280 × 720 尺寸属于旧基准，使用旧样张时先换算到 1920 × 1080。

## 3. 配色

**开始制作前先询问本次配色；用户已指定或当前项目已确认时，直接沿用，不重复询问。未确认时不自行套用默认色系。**

以下为 0.8 的纸白与克莱因蓝配色参考，仅在确认采用这套配色后使用；其他配色统一替换主色、底色与文字层级，照片中的真实颜色可以保留。

| 名称   | 色值        | 用途               |
| ---- | --------- | ---------------- |
| 纸白   | `#FBFAF7` | 页面、正文底和透明图片的承载背景 |
| 暖灰白  | `#F1EFE9` | 图片衬底、弱区块和画布外背景   |
| 克莱因蓝 | `#0026C4` | 大关键词、重点标题、图解和强调  |
| 深蓝   | `#001A8C` | 深色强调与蓝色文字层次      |
| 柔蓝   | `#8FA0E8` | 弱化标记和辅助图形        |
| 浅蓝   | `#DDE3F7` | 定义区、轻背景和图像后的浅色构成 |
| 分隔线  | `#C9D2EE` | 表格、分栏和结构线        |
| 主文字  | `#0E1220` | 标题、正文重点          |
| 次级文字 | `#39405A` | 正文说明和副标题         |
| 弱文字  | `#6E7691` | 页眉、页脚、来源和辅助注记    |

- 大面积以纸白为主，克莱因蓝集中用于重点。
- 同类内容使用相同色义，避免一页一个强调色。
- 自绘的内容区底色与纸底一致，避免无意混入纯白矩形；证据截图可保留原色。
- 数据图表需要多类区分时，可以补充少量可辨识的颜色，并配合标签、线型或形状区分。
- 需要更换品牌色时统一替换色系，保持原有层级关系。

## 4. 字体与信息层级

### 字体

中文优先使用清晰的无衬线字体，如 HarmonyOS Sans SC、思源黑体、Noto Sans CJK SC、微软雅黑；macOS 可使用苹方。编号和少量注记可配 Cascadia Mono、Consolas 或 SF Mono。

每份 PPT 选定一套实际可用的正文字体，等宽字体作为辅助。正文不频繁更换字体；标题主要通过字号、字重和颜色建立层级。等宽字体缺少中文字形时，明确设置中文回退字体。

### 固定字号

用户或项目未另行指定时，全稿同一层级固定使用以下字号，不逐页或逐段单独调小：

| 文本层级 | PPT 字号 | 1920px 宽设计稿对应值 |
| --- | --- | --- |
| 一级标题 | 40pt | 80px |
| 二级标题 | 32pt | 64px |
| 正文 | 24pt | 48px |

同页尽量使用两种字号；确实同时有一级标题、二级标题与正文时，使用三种。图注、表格、来源和必要说明归入已有层级，不另外增加小字号。内容放不下时先精简、调整布局或拆页，不缩小局部文字。

上表按 13⅓ × 7½ 英寸宽屏 PPT 换算。PPT 使用 pt，Figma／网页使用 px；其他页面尺寸按比例映射：

`字号 pt = 设计稿字号 px × PPT 页面宽度 pt ÷ 1920`。

### 阅读顺序

- 每页建立一个首要阅读对象：主题词、结论、核心数据或主图。
- 概念解释页让概念词占较大视觉比例，说明文字放在其旁边或下方。
- 中文标题优先按语义换行，避免拆开固定词组。
- 标题可使用较粗字重，正文保持常规字重；只强调真正关键的短语。
- 不为填满版面拉宽中文字符间距；等宽英文注记可适度增加字距。

## 5. 页面类型与节奏

| 页面类型 | 推荐组织方式 | 注意点 |
| --- | --- | --- |
| 总封面 | 大标题＋一句主题说明＋一幅主视觉 | 建立全稿的视觉印象，少量信息即可 |
| 章节封面 | 章节名＋编号＋主视觉，可加简短主题词 | 每个大章节有清晰停顿；页数很少时按需要使用 |
| 概念解释 | 大概念词＋一句定义＋关系图或例子 | 概念词从小角标提升为主要视觉元素 |
| 流程说明 | 输入、步骤、产出或反馈关系 | 箭头表达真实方向，标注靠近对应步骤 |
| 对照比较 | 统一维度的两栏、多栏或表格 | 对齐同类信息，便于横向比较 |
| 数据结论 | 一项主要发现＋图表＋必要说明 | 保留单位、来源和影响理解的条件 |
| 作品与案例 | 大图或真实截图＋短说明＋过程或成果 | 实物和界面承担主要证据 |
| 总结 | 少量核心观点或下一步行动 | 形成收束，避免复制整份目录 |

在不同页面之间交替使用大图、定义条、流程、对照和留白构图。页数由内容决定，不固定章节名称、案例数量或总页数。

## 6. 封面主视觉与图片处理

### 选图

优先顺序：用户已有作品与素材、合适的真实摄影或素材库图片、经允许生成的图像。需要补图时根据主题和构图方向搜索，保存作者、来源、许可信息与原图。

图片题材随内容选择。人物、产品、建筑、植物、雕塑或局部纹理都可以成为主视觉。天使、宗教建筑、白鸽属于这套风格可选的图像语言，不要求每份 PPT 都使用。

可借鉴半调印刷、宗教艺术图像和构成主义拼贴中的轮廓、尺度差、留白与错位关系。风格参考用于指导图片处理和构图，不替代实际素材来源，也不照搬整张参考作品。

主视觉优先由真实图片处理而来，不用代码绘制的示意性人物或物体代替高质量图片。代码可用于裁切、蒙版、色调、半调和导出；结构图、表格和流程图可使用原生图形。

### 构图

- 封面可采用左文右图，主图约占页面四至五成宽度；也可以按素材方向镜像布局。
- 主体应足够大，让轮廓、表情、结构或质感能在投影中被看见。
- 留白与人物朝向、产品形态或建筑走势配合，文字避开复杂区域。
- 需要时用浅蓝圆形、淡色几何或局部叠影承托图像。
- 主视觉可以在总封面和一个章节页呼应，其他章节通过题材、裁切和尺度变化形成节奏。

### 处理步骤

1. 保留原图，先确定裁切和主体位置。
2. 对需要融入纸底的主体抠图，保留透明背景和独立蒙版。
3. 清理边缘残色，保护脸部、手部、轮廓和细小结构。
4. 根据页面用途选择原色、低饱和或蓝白双色处理。
5. 半调网点保留明暗层次，避免将细节变成一片实蓝。
6. **选择性过渡**：主体关键轮廓保持清晰，底部、次要边缘或建筑外沿可逐渐淡入纸白。
7. 按最终展示尺寸检查锯齿、光晕、残留矩形底和渐隐断层。

抠图用于需要融入版面的图片；作品截图、数据证据或完整场景可以保留矩形边界。渐隐只处理适合弱化的部分，不能让整个主体失去清晰度。

PPT 使用透明 PNG 或兼容的矢量素材；网页版可另外输出 WebP。优先保留图片的可用分辨率，不拉伸变形。

## 7. 半调、几何与页眉页脚

### 半调纹理

纸底网点保持低对比，集中在边缘和空白区。正文下方使用干净纸底，密集网点主要用于图片处理或局部构成。全稿的网点尺度和浓淡保持一致。

### 线与形

- 细线用来分组、连接、对齐和标注，推荐在 1920px 基准下使用约 1–2px。
- 圆弧、光晕和几何图形可以靠边或部分出画布，但不遮住标题和页码。
- 不在主图旁额外摆放无意义的粗横条、粗竖条和底座条。
- 表格边线、流程线和重点区域的短边线按信息需要使用。
- 结构线经过标签时，线应避开文字或位于标签底色之下。

### 页眉页脚

章节名、页码和小型项目标识保持固定位置。少量等宽注记可提供图纸感，但注记应简短且与内容相关。

项目名随任务替换，不把旧项目名、年份和主题词沿用到新稿。白鸽等图标为可选标识；使用纸白图标挖版时，要有足够的底色或网点对比。

页面正文、主要图像、标注、装饰之间需要清楚的前后关系。特别检查叠放后的文字、图解和图片，不让大面积底色遮掉内容。

## 8. 内容呈现与资料入口

原稿标题和结构是信息组织依据。允许为排版提炼短标题、拆分内容，但保留主题名称、关键事实和逻辑关系。

页面使用观众能直接理解的材料。编辑待办、生成过程、对委托人的对话和无关的防御性说明不进入正文。数据单位、来源、假设和影响结论的限制仍按内容需要保留。

案例页可以放置小型缩略图或简洁链接，让作品、视频、原始资料或工程文件便于打开。入口保持次要层级，主要画面用于展示内容。

资料署名可放在页面来源区或备注中；许可要求必须可见时按要求显示。引用截图、图表、作品和文字时保留可追溯信息。

## 9. PPT 文件制作与交付

- 标题、正文、标签和关键数字使用原生文本，便于修改和搜索。
- 表格、数据图表和需要编辑的流程优先保留原生对象；照片、半调纹理和拼贴作为图片保留。
- 确认目标电脑上的字体，必要时在字体许可允许的范围内嵌入或使用已验证的替代字体。
- 视频可嵌入或链接；链接到本地文件时明确随稿交付的素材位置。发给他人时不能依赖制作者电脑的盘符。
- 网页转 PPT 时保留内容、比例和主要视觉，把交互入口改成实际可用的链接或幻灯片跳转。
- 画布、页码、图片和文本转换后逐项核对，网页预览不能代替 PPT 的实际渲染。
- 保留素材原图、处理结果、来源记录和制作文件，方便再次修改。

## 11. 下次制作时可直接附上的要求

> 请按这份《PPT 通用设计规范》制作本次演示文稿。使用 16:9、1920 × 1080 的视觉基准，配色未确定时先询问，已有约定则直接沿用。采用清晰的大标题、适量半调纹理和克制的几何构成；未另行指定时，一级标题 40pt、二级标题 32pt、正文 24pt，同层级全稿固定。根据我提供的内容确定章节和页数，沿用主要标题，为大章节设置独立封面。主视觉优先使用真实图片，经抠图、色调与半调处理融入页面，关键轮廓清晰，局部可做柔和渐隐。不要添加无意义的粗横条或竖条，不要把所有页面做成相同卡片。文字和需要修改的图表保持可编辑，最后在演示软件中逐页检查。
