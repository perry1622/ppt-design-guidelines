# PPT 通用设计规范

一份面向课程展示、设计调研、研究报告和方案汇报的中文设计规范。可供设计师直接参考，也可以作为 AI 助手制作 PPT 或 Figma 汇报页面时的任务约束。

**当前版本：[1.5](versions/PPT通用设计规范1.5.md)** · [历史 Release](https://github.com/perry1622/ppt-design-guidelines/releases)

## 这份规范关注什么

当前推荐 1.5：以 0.8 的视觉与制作方法为主体，只补充两项规则。

- 保留真实图片、抠图、半调印刷质感、大标题、留白与多样版式。
- 未另行指定时，一级标题 40pt、二级标题 32pt、正文 24pt，同层级全稿固定。
- 制作前先确认配色；已有约定直接沿用，不重复询问。0.8 的纸白与克莱因蓝仅作可选参考。
- 保持原生文字及需要编辑的图表、流程可修改，并检查实际导出效果。

用户或项目的明确要求优先。

## 如何使用

1. 选择并下载一个版本。
2. 提供本次内容、受众、展示形式、目标软件和已有参考；已有设计要说明哪些结构需要保留。
3. 将所选规范作为附件或任务参考，允许项目明确要求覆盖默认值。
4. 在目标软件中检查实际字体、文本编辑、图层、照片裁切及导出效果。

可直接使用的任务说明：

> 请按附件《PPT通用设计规范1.5》制作。沿用真实图片、半调处理、大标题与留白构图；配色未确定时先询问，已确定则直接沿用。未另行指定时，一级标题 40pt、二级标题 32pt、正文 24pt，同层级全稿固定。保持文字与关键图形可编辑，完成后检查实际页面与导出效果。

## Figma 与 PPT 的区别

- “40 / 32 / 24 号”是 PPT 字号约定，不能把它们机械当成任意 Figma 画布的像素值。
- 没有缺失字体、未锁定和使用原生 Text 图层，都是编辑检查的一部分，导出图片正确并不等于编辑体验已验证。
