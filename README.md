# PPT 通用设计规范

一份面向课程展示、设计调研、研究报告和方案汇报的中文设计规范。可供设计师直接参考，也可以作为 AI 助手制作 PPT 或 Figma 汇报页面时的任务约束。

**当前版本：[1.3](versions/PPT通用设计规范1.3.md)** · [下载 Release](https://github.com/perry1622/ppt-design-guidelines/releases/latest)

## 这份规范关注什么

- 保留事实、证据和原稿结构，不用模板套话替代内容。
- 已有流程图、节点或分组时，优先在原结构上整理。
- 没有图形结构且信息量较少时，优先考虑简洁的信息图形化排版。
- 通过对齐、分组、主图与细节建立层次，避免满页卡片和机械分栏。
- 字体优先 MiSans；不可用时可选清晰易读的替代字体，不固定配色。
- 同页尽量不超过两种字号；完整三个文本层级时可用三种。未指定时，一级标题 40 号、二级标题 32 号、正文 24 号。
- 保留可编辑文字与图形；Figma 页面完成后解散不必要的内容分组，保留最外层画框。
- 检查真实写入、导出效果和内容同步，区分完成状态与待补充内容。

这些是可调整的协作规则，不是强制行业标准，也不能代替实际画面检查。用户或项目的明确要求优先。

## 如何使用

1. 选择并下载一个版本。
2. 提供本次内容、受众、展示形式、目标软件和已有参考；已有设计要说明哪些结构需要保留。
3. 将所选规范作为附件或任务参考，允许项目明确要求覆盖默认值。
4. 在目标软件中检查实际字体、文本编辑、图层、照片裁切及导出效果。

可直接使用的任务说明：

> 请依据附件中的《PPT通用设计规范1.3》整理本次内容。保留原稿的事实和已有图形关系；没有图形且信息量较少时优先考虑图形化排版。保持文字和关键图形可编辑，不添加无信息的装饰文案。项目另有明确要求时以项目要求为准，完成后检查实际页面与导出效果。

## Figma 与 PPT 的区别

- “40 / 32 / 24 号”是 PPT 字号约定，不能把它们机械当成任意 Figma 画布的像素值。
- Ungroup 指解散不必要的内容分组；保留页面画框、必要遮罩和功能结构，解组后核对视觉效果。
- 没有缺失字体、未锁定和使用原生 Text 图层，都是编辑检查的一部分，导出图片正确并不等于编辑体验已验证。
